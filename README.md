## ✨ Features

- ✅ Add, Edit & Delete Tasks
- ✅ Undo / Redo
- ✅ Priority Levels
- ✅ Due Dates
- ✅ Tags & Search
- ✅ Subtasks
- ✅ Bulk Actions
- ✅ Drag & Drop
- ✅ Import / Export JSON
- ✅ Cross-tab Synchronization
- ✅ Offline Support
- ✅ Light / Dark Theme
- ✅ Keyboard Shortcuts
- ✅ Responsive Design
- ✅ Animated 3D Statistics

## 🛠 Tech Stack

- React
- Redux Toolkit
- Vite
- JavaScript
- CSS3
- @dnd-kit
- React Three Fiber
- localStorage

## ⚙️ Installation

```bash
git clone https://github.com/mannuDev/makeittodo.git
cd makeittodo
npm install
npm run dev
```

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| N | Focus New Task |
| / | Search |
| Shift + A | Mark All |
| Ctrl + Z | Undo |
| Ctrl + Shift + Z | Redo |
| Esc | Close Dialog |
| ? | Help |
